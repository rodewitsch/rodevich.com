About Me

I'm a software engineer based in Minsk, Belarus, currently working at LLC LWO. I specialize in building browser extensions, developer tools, and full-stack web applications.

My passion lies in creating tools that solve real-world problems for developers — from automatically authorizing Swagger API requests to helping people learn English through browser extensions. I have a strong background in JavaScript/TypeScript ecosystems and enjoy working across the entire stack, from backend APIs in NestJS and Express.js to desktop apps with Electron.js and mobile apps with React Native.

Beyond coding, I'm a contributor to open-source projects and hold the Arctic Code Vault Contributor badge — my code is preserved in the Arctic World Archive for future generations.
